# Mithril Dataset Python SDK 0.1.0

Experimental reference-profile SDK. Requires Python 3.10+ and Node.js 24+ on PATH
(or `MITHRIL_DATASET_NODE`); Zstd requires Node's built-in Zstd functions.
This SDK materializes the dataset and invokes the packaged Node evaluator.
It is not an independent Python decoder, streaming reader or Iceberg engine.

Install from this repository with `python -m pip install './sdk/python[arrow]'`.
A PyPI release has not been published. See the repository's Dataset Quickstart.
