No flag means a normal function; generator produces function*, async produces async function, both produce async function*. False flags retain ordinary function artifact bytes. These are real current-realm JavaScript functions and coroutine objects, with native prototype/constructor identity, descriptors, nonconstructibility, own this/arguments/new.target, defaults/rest, deferred generator bodies and native return/Promise assimilation.
