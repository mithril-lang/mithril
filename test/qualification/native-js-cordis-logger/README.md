# Complete Cordis logger runtime source

[The Mithril source](../../../examples/native-js-cordis-logger.mith) expresses the entire pinned original logger runtime: five exports (defaultFormatters, Logger, c16, c256, LoggerService), both complete classes, all formatters and palettes, the private aggregate-error helper, severity methods, callable service/context handling, exporter disposal and buffering. It uses the existing native class/static-block/lexical-arrow/bitwise/module-TDZ prerequisites and the checked source control flow added here. Candidate logger receives defineProperty/hyphenate from the genuinely compiled complete CosmoKit package and createCallable/joinPrototype/symbols from genuinely compiled complete utils, not substitute helpers or original-code imports.

HostReturn(value), HostContinue and HostBreak are admitted only in real statement positions. Explicit statement bodies of module functions, normal functions, arrows and class signatures establish their own return target and reset loop context. For-of/while bodies establish the nearest source loop. Static blocks admit loop transfer in their loops but cannot return. Values/operands/initializers/defaults/class keys/heritage and helper-IIFE results cannot transfer control to an enclosing source function or loop. Nested functions cannot borrow an enclosing loop. Emission uses actual return/continue/break statements with native finally and IteratorClose behavior; no exception-based surrogate transfer is used. Unary minus is also admitted as the actual operator, preserving negative zero and BigInt rather than spelling it as zero subtraction.

The source preserves the original severity/threshold order, Date.now timing, cause recursion versus aggregate early return, exporter iterator order/throw boundary, metadata spread override and args placement, field/parameter-property assignment order, buffer callback's undefined result, noShadow origin fiber, intercept prototype walk and its malformed-null failure, callable dispatch and subclass behavior. Native unary minus is used for slice(-bufferSize), including negative zero and BigInt values passed to an overridden slice. Getter/default behavior, formatter call receivers, original hash overflow and real class/arrow shape remain observable as in the source.

No host intrinsic is mutated and neither original helper implementation nor source evaluation is present in candidate output. The adapter evaluates test-only reference code. This is finite Node/VM source compatibility evidence, not actual browser execution or universal equivalence.
