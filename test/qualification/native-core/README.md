# Complete Cordis core source in native ESM

The four complete program runtime modules context/events/fiber/registry are independently authored as checked Mithril forms, linked with the complete compiled CosmoKit/utils/logger/reflect dependencies. The package contains 14 real native ESM modules and exports the original four-module core's nine values. Class fields/static branding, constructors, getters/methods, Inject namespace/decorator/resolve, full event modes and Fiber config/effect/state/epoch/load/unload/update/restart code are present. This is the core subgraph, not the final service/index public barrel or full Harness.

Authoring used the pinned original program AST as an operator-side inventory; emitted source/compiler/runtime do not invoke TypeScript, evaluate raw JS, import the original graph or weaken existing admission budgets. Source loop bindings that shadow parameters/locals are alpha-renamed with references in their exact scope; literal property keys and function/class names remain original. Optional catch without a source binding receives an unused fresh checked binding. Existing native statement/coroutine/continuous-chain/namespace/parameter machinery is used without compiler changes.

Qualification adds 2 tests / 4 assertions. Both actual js/js-browser native-ESM CLIs execute 24 paired groups each (48 total) in Node against the complete pinned original program graph. All reference module bodies are unchanged except explicit static import basenames; hashes and each import-only adaptation are checked. Actual Context/Events/Fiber/Registry owners are used, including branding/initialization/scopes, event modes/bail/parallel errors/waterfall, standard-schema validation, class and method Inject, callback/object/class plugins, restart/update/disposal, dependent service activation/unload, synchronous/async generators, failed setup, reentrant publication/failure rollback, shared runtime deletion and owner joining cleanup already started by another caller. Plugins/schema validators/deferred promises are controlled inputs, not substitute owners.

Existing checked package/frozen leaf and strict CosmoKit declaration controls pass. These finite runtime groups do not prove every race/error-text/stack scenario, original whole-project build/tsdown, real browser/native/Q9, Cordis public class/interface/augmentation/const-enum typing or new-profile declarations.
