## Generic language additions

- LocalSet writes only explicitly mutable lexical bindings and returns the native
  assigned value; mutable Let/module bindings survive closure capture, while
  immutable/parameter shadows mask write authority.
- HostThrow and expression-valued HostTryFinally retain opaque throw identity,
  normal/abrupt cleanup and cleanup-throw precedence without awaiting values.
- Closed binary whitelist adds `in` with native inherited/symbol/Proxy behavior.
- LocalFunction creates a normal named constructible recursive function with
  captured outer locals. Its self binding exists in body/result, parameters only
  in body. Generated identifier prefixes avoid original local-function names.
- Optional sequential module bindings run once before function declarations per
  factory instance; initializers only see earlier bindings and no function refs.
  Functions share that instance's state and different instances remain isolated.
- Optional top-level native parameter defaults use native initializer semantics,
  including undefined-only lazy evaluation, length and later/self TDZ behavior.
- Explicit HostObject infer_name opts a NativeLambda property initializer into
  native string/symbol name inference, evaluating the property key once. Existing
  unannotated arrows remain anonymous with unchanged emitted bytes.

Optional fields stay optional with strict exact shapes. Shared source/node/depth
budgets apply to all additions. Legacy bounded guest context still refuses this
trusted native JS profile; opaque runtime values are not inspected by a guest ABI.
Old checked IR shape and mapValues/misc/array emitted bytes are preserved.
