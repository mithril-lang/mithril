# Complete Cordis utils runtime source

[The Mithril module](../../../examples/native-js-cordis-utils.mith) expresses the complete runtime content of pinned `vendor/cordis/src/utils.ts`: 11 exports, 17 shared Symbol.for values, DisposableList, constructor probes, prototype/descriptor walking, property overlays, traceable service/context proxies, callable services and error composition. All private helpers remain private. It uses checked native AST; the runtime compiler neither reads original TypeScript nor executes source strings or a substitute helper implementation.

`Let` bindings now accept an optional exact boolean `recursive`. When true, only that binding is available in its own initializer, with its declared mutability. Lowering allocates its fresh identifier before lowering the initializer and emits real const/let initialization. Reads or assignments before initialization throw native ReferenceError. Forward references to later bindings and writes through immutable bindings remain refused. Default/false paths preserve the prior symbol allocation order. This supplies the actual self-capture used by createTraceable's proxy and createCallable's anonymous function without changing their architectures.

NativeLambda, NativeFunction and class constructor/method/accessor signatures accept optional exact boolean `statements`. True lowers the existing checked body directly to native statements; omitted/false retains expression-body lowering. Arrows preserve their lexical contexts; normal functions preserve their own contexts. Fields do not accept this flag. The whole source uses direct bodies so helper IIFEs do not add stack frames to error composition. Existing HostLogical `??` and HostToString native template coercion are reused, including Symbol conversion failures.

Source details preserve the original constructor heuristic, repeated tracker/associate reads, descriptor-versus-getter paths, symbol bypass, receiver forwarding, noShadow branch, method-result tracing, `symbols.invoke` redirection and original fallback Reflect.apply. The self function's original inferred name is established by checked computed-property name inference before CosmoKit defineProperty supplies the public name. The original `shadow ??=` on an ordinary local is expressed by assigning the checked nullish expression; no property setters or alternate proxy architecture are introduced.

The adapter's sole change resolves its CosmoKit import to the complete original package fixture. Runtime controls verify all three source/oracle hashes. Candidate utils receives defineProperty from the genuinely Mithril-compiled complete CosmoKit package, not an original-code shim.

Both actual js/js-browser module CLI outputs and both actual CosmoKit package CLI outputs are imported. There are 35 runtime groups plus eight paired asynchronous Promise assertions: native recursive closure identity/construction and early read/assignment TDZ; all public names/arity/symbols; constructor/object classification; prototype descriptors and symbols; descriptor search; overlay has order, invariants, symbols and readonly writes; origin/active/shadow context behavior; own versus inherited context descriptors; associated getter/setter receivers; nested and returned services; tracked function fallback and invoke redirection; callable prototype/name/arity/dispatch; disposal; exact unnormalized real default error stack and rejection identity. An isolated VM's early Proxy constructor invokes the initializer-captured apply handler before initialization and verifies native TDZ in both original and candidate. Host intrinsics are not modified.

Source suite: 33 tests / 136 assertions, including eight malformed/flag/scope/recursive refusals. Retained package controls pass 40 public exports, 15 runtime groups per actual target and seven frozen leaf artifacts. Retained CosmoKit declarations pass strict TSC6.0.3 consumers (10 positive / 12 negative groups per target), 446 type nodes and no skipLibCheck. These type controls do not qualify Cordis class/proxy declaration shapes.

Implementation is operator-authored; new System One inference requests and repairs are zero. The prior sealed declaration and package model failures are unchanged and were not adopted. This milestone therefore supplies no new model coding-performance measurement.

This is finite complete-source runtime evidence under Node and isolated VM realms, using a standalone explicit-grant factory profile. It is not universal equivalence, browser-host or native/Q9 evidence. Cordis public declarations, named package ESM composition, logger and the context/events/fiber/reflect/registry SCC, service/index, Schemastery and full Harness APIs/plugins/profiles/Session remain required. Dependency progression is CosmoKit → utils → logger → the five-file runtime SCC → service → index. The missing organization Harness destination remains a separate delivery gate; the language/compiler work is independently publishable.
