# Original Cordis public declaration oracle

Full Cordis public typing needs a declaration graph with class identity, module augmentation and compile-time-only exports. The prior Spread<T> alias control deliberately covered only a tuple prerequisite. This baseline fixes the original nine-module declaration output before extending the Mithril type language.

The nine declarations in `test/fixtures/cordis-declarations/program/` are unmodified TypeScript 6.0.3 declaration-only outputs from `deepseek-ai/deepseek-harness` commit `441416c0048aa4281bffe59c1c7b5e13e08a9ec1`, `vendor/cordis/src`. They retain relative `.ts` imports, module augmentations, private/protected class members, `out` variance, abstract service, polymorphic `this`, unique symbols, merged declarations, overloads and const enums. Original MIT licensing is in the fixture's LICENSE. The type-only standard-schema dependency is pinned to spec 1.1.0 with its own license and integrity metadata; CosmoKit uses the already pinned complete original declaration fixture.

`program-provenance.json` records original source/config hashes, all nine emitted output sizes/hashes, external type hashes and explicit adapters. Emission uses the original Cordis/base compiler options with external CosmoKit/spec paths and pinned Node26.6.3/undici8.9.0 types, non-build/non-incremental declaration-only output, no declaration/source maps and full library checking. Configuration and program diagnostics are both empty, and emitSkipped is false. This is the adapted nine-source Cordis program, not an upstream project-reference/whole-repository/tsdown build. Historical runtime-emission diagnostics under different unresolved dependency conditions remain separate evidence.

The integrated `controls/cordis-type-contract.mjs` checks fixture hashes, exact 50-name public value/type namespace (35 type bindings, 28 TypeScript value bindings including two erased const enums; 26 runtime values), built-in and external Context/Events augmentation, original plugin callback/class/object configuration contracts, protected subclass access, private nominal identity, Service covariance, volatile readonly/type-only exports and class/interface/namespace merging. Sixteen positive consumer groups pass with strict TSC6.0.3 and skipLibCheck=false; fifteen deliberate negative groups produce pinned original diagnostic codes. All consumer files belong to one program, so the external event augmentation is intentionally shared across cases. It is baseline-only: no Mithril declaration candidate is compared, and the control rejects a candidate argument. Future candidate augmentation must target that candidate's own module identity.


The existing source, complete CosmoKit declaration/runtime, named tuple, frozen artifact and actual two-target CLI qualifications are retained. Compiler production code, budget/admission guards and emitted runtime/declaration bytes are unchanged by this baseline. Eleven original class declarations, five module augmentations and class/interface/namespace merging now have a concrete reference graph, but their Mithril type language implementation, complete Cordis declaration emission and full Harness API/plugin/profile/Session/browser/native/Q9 parity remain pending.
