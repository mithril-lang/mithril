# Native mutable parameter bindings

Named normal/module/class/object method parameters accept optional boolean `mutable`; arrow named/array parameter patterns accept that flag per pattern. Absent/false flags retain immutability. String arrow parameters, loop bindings and rest bindings retain existing immutable guards. Checked LocalSet targets the actual formal/pattern symbol; no body-local parameter copies or assignment wrappers are introduced. Existing signature/name/arity/default/coroutine emission is unchanged.
