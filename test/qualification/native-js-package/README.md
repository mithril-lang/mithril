# Checked native Mithril package composition

First prerequisite: the inert `mithril/native-js-package` form has its own
native-js-package/v1 context. A checked native module can emit a private named
factory for a linker that supplies its exact declared grants. Standalone module
outputs and runtime grant validation remain unchanged. Private factories preserve
normal function values and lazy host access without extra observable reflection.
A paired runtime probe checks zero reads at factory creation, two live host reads,
normal function metadata and no reflection. Existing complete native leaf
contracts and prior artifact hashes remain required.

Package graph/link validation, public ESM compilation, original CosmoKit index
runtime equivalence, public type declarations and downstream Harness parity are
separate gates. This prerequisite alone does not provide package compilation,
qualified browser execution or System One coding performance evidence.
