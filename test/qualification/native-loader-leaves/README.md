Complete original `config/utils.ts` and `config/diff.ts` runtime source is
expressed as Mithril AST and linked with the seven own CosmoKit modules. The
original dynamic `Function` evaluator is preserved, including context shadowing,
inherited properties, unscopables and expression errors. This original API is
not an execution sandbox.

The qualification runs both actual ESM and declaration-program CLIs for `js`
and `js-browser`. Both labels execute under Node; actual browser compatibility
remains unverified. TypeScript 6.0.3 erases only the pinned original runtime
oracle and checks independent consumers. Native compilation never delegates to
TypeScript or original dependency implementations.

All four utils declarations and the comparator declaration match the complete
original declaration AST, normalizing only parentheses and export/declare
grammar. Eight positive and ten negative consumers use the complete own Cordis,
CosmoKit and Schema declaration graphs. Refusal codes and messages are paired
against the original libraries, with `strict` and `skipLibCheck: false`.

Nineteen paired runtime groups include actual original/own Schema values,
volatile paths, defaults, backedges, raw expressions, malformed schema behavior,
public function metadata, immutability and a validator/transform non-execution
control. The evaluator's actual function source also matches the original.
These finite groups do not establish universal equivalence or full Loader,
Include, Harness, plugin, profile or Session compatibility.

and complete source/declaration hashes. Original declaration emission retained
three recursive implicit-any diagnostics (7023/7024/7024), so it is not evidence
of a clean original strict source build. The original public return type `any`
