# Original Cordis optional configuration tuples

Original registry.ts defines Spread<T> as undefined extends T ? [config?: T] : [config: T]. Context.plugin uses that alias for its configuration rest arguments. The prior checked type AST could emit ordinary tuples but could not preserve a tuple label or an optional element, so the actual original alias could not be represented.

Tuple items now optionally use an exact structured named-tuple-item with name, boolean optional and datatype fields. They are admitted only inside tuple items; ordinary type nodes retain their old representation/emission. Labels are syntax rather than type/value bindings, and optional items cannot precede a required item. Existing collection/node/depth/scope/type checks remain and named wrappers charge their own node/depth. No raw source, expanded budgets or delegated TypeScript parser is added to the compiler. This adds only the actual named/optional tuple prerequisite; tuple rest/spread operations are not added.

The complete pinned original registry TypeScript source is hashed and the reference alias is checked against its exact line. A controlled echo<T>(...args: Spread<T>): T observation signature makes the alias's argument rules independently visible; it is not the complete original Context.plugin signature. Both actual CLI targets and old/native-ESM profiles emit this checked type form. Pinned strict TSC6.0.3 with full library checking passes ten positive/eight original-derived negative groups per profile/target, including required, optional, null, void, unknown, any and never configurations, conditional generic parameters, tuple length, missing/wrong/excess arguments and matching diagnostic codes. Nine malformed-shape/scope/order/collection/depth cases refuse. Existing full446node CosmoKit type AST/byte-identical ESM declaration output, strict consumer/runtime controls, source59tests209assertions and frozen package artifacts remain qualified.

Class/interface/namespace merge, variance/abstract/private/protected/unique-symbol/this, module augmentation/type graph/const enums and full Cordis public typing remain unported. This source-derived prerequisite does not establish full Harness API/plugin/profile/Session/browser/native/Q9 parity. Operator authored; zero new System One inference/repair/model adoption and no coding gain claim.
