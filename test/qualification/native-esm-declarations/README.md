# Full CosmoKit declarations on checked native ESM

The declaration checker accepts the existing checked NativeJsPackage and actual checked NativeJsEsmPackage formats, with the same package name and exact public runtime namespace requirement. The CLI dispatches the inert runtime document through its owning bounded source read plan and full graph checker. Native ESM still validates dependency/link identities, cycles/reexport origins, exact host grants, source names and all native source scopes before declaration emission. Unknown runtime kinds are refused before module reads. Type AST shape/scope/visibility/arity/budgets and old package semantics are unchanged; there is no raw TypeScript/JavaScript or runtime source delegation.

The full original checked CosmoKit declaration AST (446 type nodes, 49 public names/40 values/11 type bindings including two dual names) is bound to the existing complete seven-module native ESM runtime. Only runtime-source changes; the emitted declaration bytes are identical to the retained old profile. Both actual js/js-browser CLIs emit index.mjs and adjacent index.d.mts. Strict TSC6.0.3 consumers import that actual runtime entry path, resolve its declaration and exercise all ten positive/twelve source-derived negative groups, exact type/value namespace and mutual assignability against original types. All fifteen source-derived runtime groups are also run for each target/profile. The old profile remains independently qualified.

Three direct runtime-format/name/public-surface mismatches and eight actual CLI refusals cover unsupported target, wrong package name, malformed manifest, unsafe source basename, duplicate reads, unknown runtime kind, source symlink and runtime symlink, retaining sentinel output. Mutated runtime fixtures roundtrip as inert Mithril forms and refusal codes are checked, so syntax errors do not substitute for the intended guards. Existing generic type AST and older declaration/source/package/frozen artifact controls remain.

This connects real native ESM to complete CosmoKit typing. It does not add Cordis class/interface/namespace merge, module augmentation, const-enum or public/new-module declarations, prove all cyclic type graphs, or complete full Harness/browser/native/Q9 parity. Those are next dependencies. Operator-authored; zero new System One inference/repair/model adoption or coding gain claim.
