`mithril/native-function` is a normal function expression with exact fields name (identifier or nil), params (up to 64 js-value parameter records with optional default), rest (fresh identifier or nil), body. Its optional name is visible only inside its defaults/body and supports recursion. Rest cannot duplicate a parameter. Normal functions establish their own dynamic receiver, arguments and new.target context; nested NativeLambda and generated arrow wrappers capture it lexically. `mithril/host-this` and `mithril/host-new-target` require a source normal function context, including ordinary top-level Functions and LocalFunctions. Module initializers, exports and top-level arrows cannot use these forms directly. No raw source/eval operation is added.

Anonymous functions retain an empty name unless a HostObject initializer explicitly requests native infer_name; named functions retain their name without capturing generated helper identifiers. Defaults/rest retain JS length rules. Native normal functions remain constructible, retain native prototype descriptors and constructor-return behavior, and work as base constructors for existing JS subclasses. The compiler emits native function syntax; it does not simulate receivers through injected arguments.
